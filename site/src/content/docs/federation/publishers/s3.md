> `set-publisher -type=s3`

Publishes the discovery + JWKS documents to an **AWS S3** (or S3-compatible) bucket,
authenticated by a stored IAM access key Warden can **self-rotate**.

```bash
warden oidc-issuer set-publisher -type=s3 \
  -config=bucket=my-jwks -config=region=us-east-1 \
  -config=access_key_id=AKIA... \
  -config=secret_access_key=@/run/secrets/s3 \
  -rotation-period=720h
```

## Parameters

| Key | Required | Description |
|---|---|---|
| `bucket` | yes | S3 bucket name. |
| `region` | yes | Bucket region. |
| `access_key_id` | yes | IAM access key ID. |
| `secret_access_key` | yes | IAM secret access key (masked; use `@file` to read from a file). |
| `prefix` | no | Key prefix within the bucket. |
| `endpoint` | no | S3 API endpoint override (S3-compatible stores, private endpoints). |
| `rotation_period` | no | Self-rotate the IAM key on this cadence (e.g. `720h`; **minimum 24h**). |

Self-rotation calls **AWS IAM**, so it requires a permanent IAM-user key (`access_key_id`
starting `AKIA…`) and cannot be combined with a non-AWS `endpoint` (MinIO / R2) — the
server rejects such a config at write time. Leave `rotation_period` unset for those.
